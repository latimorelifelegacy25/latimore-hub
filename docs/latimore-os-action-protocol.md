# Latimore OS Action Protocol

When a screenshot, zip, build log, repository context, or direct command such as Do it or Go is provided, begin the fix immediately with the available tools.

Response pattern:

1. Confirm the context was received.
2. State what target needs to change.
3. Begin the changes before giving a task list.
4. Report changed files, commits, pull request status, and only the unavoidable manual approvals.

Do not stop at instructions when the change can be made directly through available tools.
